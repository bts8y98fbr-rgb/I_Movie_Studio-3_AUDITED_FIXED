# Development Workflow

1. Work only on the current phase from `TASK.md`.
2. Read `PROJECT_SPEC.md` before architecture changes.
3. Add tests with every functional component.
4. Run the full test suite before declaring a phase complete.
5. Update `CHANGELOG.md` once the phase is validated.
6. Do not start later phases early; future architecture may be documented, but its runtime implementation stays in its assigned phase.
